# AGENTS.md — ai-toolkit-reference

This file governs agent communication behavior for this repository. Company-wide
governance and Owner communication requirements are canonical in
[`ai-operating-system/.claude/GLOBAL_CLAUDE.md`](https://github.com/SiiYa-Ventures-Corporation/ai-operating-system/blob/main/.claude/GLOBAL_CLAUDE.md)
and [`ai-operating-system/governance/contracts/OWNER_COMMUNICATION_CONTRACT.md`](https://github.com/SiiYa-Ventures-Corporation/ai-operating-system/blob/main/governance/contracts/OWNER_COMMUNICATION_CONTRACT.md).
This file does not create a competing governance layer — repository context for
this repo lives in [`CLAUDE.md`](./CLAUDE.md).

- Lead with the material result, decision, failure, or blocker.
- Every Owner-facing status update uses the compact phase/task table (Phase | Task
  | Completion | Agent | Status), not narrative — see the Owner Communication
  Contract §6.
- Keep detailed evidence, command logs, and investigation history in canonical
  GitHub records (issues, PRs, `ai-operating-system/governance/`).
- Do not narrate routine execution or every command.
- Surface true failures, blockers, and material risks promptly.
