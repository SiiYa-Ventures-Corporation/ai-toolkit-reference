## What Are Skills?

Skills are workflow definitions that teach Claude Code how to perform specific tasks. They live in `.claude/skills/` as markdown files with YAML frontmatter.

## Skill File Format

```markdown
---
name: my-skill
description: "When to trigger this skill"
---

# Skill Name

Steps and instructions here...
```

## How to Use Skills

Skills are automatically invoked when Claude Code detects a matching trigger in your prompt. You can also reference them directly:
- "Use the scoring-engine-owner skill to review this proposal"
- "Follow the gitnexus-debugging workflow to trace this bug"

## How to Create New Skills

1. Create folder: `.claude/skills/custom/<skill-name>/`
2. Add `SKILL.md` with frontmatter + workflow steps
3. Optionally add `assets/`, `references/`, `agents/` subfolders
